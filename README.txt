HOW TO VIEW AND DEPLOY THIS SITE (Diego's Portfolio)
=====================================================

WHAT THIS FOLDER MUST LOOK LIKE
This folder must contain, side by side:
  1. index.html          (the website)
  2. assets              (folder with all 17 images + resume PDF)
  3. README.txt          (this file)

If you are reading this file, you are in the RIGHT folder.
The index.html in THIS folder is the one to open. Any other
index.html on your computer (for example in Downloads) is an
old copy and will show no images.

TO VIEW LOCALLY
  1. Stay in this folder
  2. Double-click index.html (the one right next to this README)
  3. All photos will display. Videos may not play locally
     (Wistia blocks local files) but they work once deployed.

TO DEPLOY TO NETLIFY
  1. Go to app.netlify.com and open your project
  2. Click the "Deploys" tab
  3. Drag THIS ENTIRE FOLDER onto the drop zone
  4. Wait for "Published", then hard refresh your live site
     (Ctrl+Shift+R)

The live site is what matters. If diegojimenezu.netlify.app
shows all the images, everything is working correctly.
